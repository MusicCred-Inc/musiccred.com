# musiccred.com

Public website for MusicCred, Inc. Static HTML on GitHub Pages, served from the `main` branch (root). No framework, no dependencies at runtime.

## Pages

| URL | File | Notes |
|---|---|---|
| `/` | `index.html` | Home: hero, press, how it works, features (App Store screens), testimonials, MusicCred Cares, founder, CTA |
| `/about/` | `about/index.html` | About, why MusicCred, founder bio, endorsements |
| `/support/` | `support/index.html` | Support & FAQ (the apps link here) |
| `/privacy-policy/` | `privacy-policy/index.html` | Privacy Policy. This exact URL is on the App Store listing |
| `/tos/` | `tos/index.html` | Terms of Service (the apps link here) |
| `/404.html` | `404.html` | Served by GitHub Pages for unknown paths |

`about.html`, `support.html` and `privacy-policy.html` are full copies of the directory pages so that the extensionless URLs (`/about`, `/support`, `/privacy-policy`) work on GitHub Pages. The other legacy names (`/privacy.html`, `/privacy/`, `/terms.html`, `/terms/`, `/terms-of-service/`) are tiny redirect stubs. Keep them; old links in emails and app builds still use some of them.

## Design and assets

- Brand: black `#141314`, gold gradient `#A88424 -> #D2BA79 -> #A88424`, purple accent `#5005A9`, Montserrat (Google Fonts). Same palette and header logo as the mobile app (`assets/header-logo.svg`, `assets/crown.svg`, `favicon.svg`).
- `assets/screens/*.{webp,jpg}` are the five App Store screenshots of the shipped app (v1.4.1), cropped to the phone. `assets/icon-512.png` is the App Store icon; `assets/og.png` is the social preview.
- All content is first-party: the App Store description, MusicCred press releases (AristoPR, Jan-Feb 2024), the Mayor of Destin endorsement release, the Jessie G x MusicCred release, published reviews/interviews, and the previous musiccred.com. Quotes are attributed to their sources.

## Editing

The HTML is generated by a small Python script (`build_site.py`, kept with the relaunch files in the MusicCred Dropbox under `MusicCred IS BACK/website/`). Either edit the HTML here directly and commit to `main` (GitHub Pages redeploys in about a minute), or edit the script and re-run it. Keep in mind:

- Contact address everywhere is `support@musiccred.com` (an alias on Google Workspace).
- The legal pages are the April 25, 2023 versions, reproduced verbatim. Any change to them goes through counsel first.
- Do not add claims about patents. The provisional applications filed in 2023 were not converted.
- Deep links for the mobile apps are configured for `app.musiccred.com`, not this host. When the platform is rebuilt, that host must serve `/.well-known/assetlinks.json` and `/.well-known/apple-app-site-association`.

## Hosting and DNS

- `CNAME` contains `musiccred.com`; the GitHub Pages custom domain is set to the same value. `.nojekyll` disables Jekyll processing.
- DNS is managed at Wix (nameservers ns8/ns9.wixdns.net). Apex A records point at GitHub Pages (185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153); `www` is a CNAME to `musiccred-inc.github.io`. Mail (MX, SPF, DKIM, DMARC) stays on Google Workspace.
- `robots.txt` and `sitemap.xml` list the five canonical pages.
